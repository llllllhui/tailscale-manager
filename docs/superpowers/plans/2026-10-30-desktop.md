# 桌面版实现计划

已确认方案见 `../specs/2026-10-30-desktop-design.md`。

1. 将 Tailscale 操作从 HTTP 路由提取为共享函数，验证正常、权限不足、非法地址和登录超时结果。
2. 增加 GTK 应用、WebKit 消息桥、托盘菜单、单实例和设置保存，验证工作线程不阻塞窗口。
3. 为现有界面接入消息桥，修复异步操作恢复和复制反馈，补充深色模式及窄窗口适配。
4. 添加标准桌面入口、用户安装器和 `.deb` 构建脚本，验证安装文件不依赖源码目录。
5. 执行单元检查及实际桌面启动检查，生成安装包、更新使用说明，并安装到当前用户应用列表。

验收：从应用列表启动独立窗口；托盘可操作；关窗常驻且可唤回；重复启动不产生第二个实例；可选自启动；有可交付的安装包。
