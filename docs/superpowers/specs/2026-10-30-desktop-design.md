# Tailscale Manager 桌面版

用户已于 2026-10-30 确认以下方案：Ubuntu 可安装的桌面 App，拥有独立窗口、常驻托盘和可选登录自启动。

## 体验与范围

- `.deb` 安装后可从应用列表打开，中文界面和系统窗口装饰正常显示。
- 托盘显示连接状态，提供连接／断开、复制 IP、出口节点、打开窗口、自启动和退出。
- 关闭窗口后继续驻留；如果桌面没有可用托盘，关闭窗口正常退出，避免无法唤回的后台进程。
- 重复启动唤回同一窗口；后台启动不抢占窗口。
- 保留现有状态、设备列表、延迟检测和登录功能；退出管理器不改变 VPN 连接。
- 自启动由用户选择；已有官方托盘自启动在开启新管理器自启动时备份并停用，避免下次登录出现两个托盘。

## 实现

使用系统 Python、GTK 3、WebKitGTK 4.1 和 Ayatana AppIndicator，复用 `ui.html` 和 Tailscale CLI 后端。`Gtk.Application` 通过桌面会话 D-Bus 保证单实例。桌面界面通过 WebKit 消息桥与应用通信，不启动 HTTP 服务。CLI 操作在工作线程执行，主线程负责窗口和托盘。

设置放在 XDG 用户配置目录。安装文件可放在系统只读目录，程序运行不写源码目录。保留原有 HTTP 服务作为开发工具，桌面启动器改为启动桌面 App。

## 异常处理

依赖缺失显示明确的安装提示；守护进程不可用、无权限、命令超时及登录需求显示在窗口或托盘操作提示中。外部登录链接交给默认浏览器，应用窗口限制在自身界面内。没有托盘宿主时保持窗口可见。

## 验证

检查后端操作分发、错误和登录 URL 处理；配置和自启动迁移使用临时目录测试。实际启动 GTK/WebKit，检查页面渲染、桥接、托盘导出、单实例、隐藏与唤回、退出清理。构建并检查 `.deb` 内容、依赖、权限和桌面入口。对真实 Tailscale 仅做只读状态验证，连接切换用替身验证，避免中断正在使用的网络。
